## IV-F. Rules

| Label | Where handled |
|---|---|
| IV-F1 | Frames 1, 2 and 9 state it. The top bar after a search shows city and state, never the zip. The plan is drawn from the zip-area center. No device location or street address is asked for anywhere |
| IV-F2 | Frame 9 "Nowhere else". The plan is drawn in the browser, so no map service is fetched. One optional exit: "Open in your device's map app" in frame 6, taken only by the visitor's choice, with what that app learns stated beside it; the operator would have to accept or remove it |
| IV-F3 | Named only in the statement of the exclusion (frames 1, 4 legend, 8). No brand of it is named; the text points to the exclusion set. No example shop uses any such name, and the words chosen for the drawing are "plan", "zone" and "circle" |
| IV-F4 | Frame 6 and frame 7: score table plus a source and check date for each certification and concern |
| IV-F5 | Frames 6, 7 and 7b: a dispute link on every concern, certification, chain fact and under every score table |
| IV-F6 | Frame 7 and 7b: the claim is in quotation marks as the source's title, with source and date. Rows and marks carry no grade; the only site-made words are counts and kinds ("Concern: 1, labor, 2023") |
| IV-F7 | "Nothing found, for or against" on rows in frame 4; "the middle, unknown is not bad" in the score table in frame 6; "no chain fact; that does not prove it is independent" in frame 6. Marks look the same with or without findings |
| IV-F8 | Tags are prefixed "Chain:", "Certification:" or "Concern:" and share one plain style. The chain box in frame 7 says it is neither praise nor criticism and does not change the score |
| IV-F9 | Not drawn. See IV-E3: a separate strip off the plan, without numbers or scores |
| IV-F10 | Every frame is drawn at 360 px. The plan is 326 px wide there, and the list under it carries everything the plan shows |
| IV-F11 | Described, not testable in a static wireframe. The list repeats the plan as text in the same order; marks are links to their rows; controls are plain buttons and check boxes; frame 3 has no motion |
| IV-F12 | Thin: frame 5 and 5b. Guess: "likely", "possibly", "not a stock check", "call first" in frames 4 and 6. Failed: frame 10b. Budget: frame 10. Measured accuracy: legend in frame 4 and frame 8 |
| IV-F13 | All distances are in miles, in every frame |
| IV-F14 | No web excerpts appear. Online rows show only the matched listing title, which the inventory lists as a field. The designer's caution: a listing title could itself carry an excluded name and would need the same check |
| IV-F15 | Frame 8: "Nobody pays to be on the plan". No such element appears in any frame |
| IV-F16 | Frame 8: data credits line. Link in frame 1 |
