Notes on method
- Page ids follow the file names in `text/` and `triage.md` (for example p04 is the Good On You Patagonia page). They are not the row order of `triage.tsv` (there row 5 is that page). I checked each file's title against the URL list before answering.

- Top-99 checks: I compared names on a page with the first 100 data rows of `shop-domains.tsv` (sorted by results, ties at 6 results cut arbitrarily at row 100). "Exact" means the same name; "likely" means probably the same company (for example TJX and T.J. Maxx).
